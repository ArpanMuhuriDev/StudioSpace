JamPad Setup

Connect your app to Google Sheets in 5 minutes · One-time setup

1
Create a Google Sheet
Go to sheets.google.com and create a new blank spreadsheet.

Name it anything — e.g. JamPad Bookings.

✓ TIP  Both users should use the same Google account, or you can share the sheet later.
2
Open Apps Script
Inside your Google Sheet, click the menu:
Extensions → Apps Script

A new browser tab opens with a code editor. You'll see a default empty function. Delete everything in that editor.
3
Paste the backend code
Open the file Code.gs (provided alongside this guide).

Copy the entire contents of Code.gs and paste it into the Apps Script editor.

Then click the 💾 Save button (or press Ctrl+S / Cmd+S).
4
Deploy as a Web App
In the Apps Script editor, click the blue Deploy button (top right) → New deployment.

  1. Click the ⚙ gear icon next to "Select type" → choose Web app
  2. Description: type anything like JamPad API
  3. Execute as: Me
  4. Who has access: Anyone  Important
  5. Click Deploy

Google will ask you to Authorize — click through and allow access. This is normal and safe; it's your own script accessing your own sheet.
5
Copy your Web App URL
After deployment, Google shows you a Web App URL. It looks like this:
https://script.google.com/macros/s/AKfycb.../exec
Copy this URL. This is your database endpoint. Keep it safe — anyone with this URL can add bookings.
6
Connect the app
Open index.html (the JamPad app) on your phone.

Tap the ⚙ gear icon in the top right corner.

Paste your Web App URL into the field and tap SAVE & CONNECT.

✓ Done!  The app will immediately load all bookings from your sheet.
7
Set up the second phone
Open index.html on the second phone (share the file via WhatsApp, email, or host it on GitHub Pages).

Tap ⚙, paste the same Web App URL, and tap SAVE & CONNECT.

Both phones now read and write from the same Google Sheet. Any booking made on one phone appears on the other after tapping the ↻ sync button.
🌐
Host on GitHub Pages (recommended)
So both phones can always access the latest version via a URL:
  1. Create a free account at github.com
  2. Create a new repository named e.g. jampad
  3. Upload index.html and manifest.json to the repo
  4. Go to repo Settings → Pages → Source → main branch → Save
  5. Your URL: yourusername.github.io/jampad

Open this URL on any phone → tap Add to Home Screen → it installs like an app.

You're All Set 🎸

Your JamPad app is now connected to Google Sheets.
Both phones share one live database.
Your bookings also appear as rows in the Sheet — filter by date anytime on your laptop.
